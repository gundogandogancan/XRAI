# XRAI Engineering Skill: xrai-privacy-threat

List asset/adversary/purpose/data classification. Deny-by-default network and cloud; scoped opt-in; test Keychain, Secure Enclave, caches, backups, deletion and real-device traces. No fictional unbreakability.

## Required output
1. Referenced source and exact method/algorithm version.
2. Proposed file-level changes, scopes and data classes.
3. Observable negative/positive test plan and actual evidence.
4. Remaining blockers.

Do not call external APIs, train on private PDFs, spend money or change unrelated modules.
